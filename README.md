# Nguyen Khac Trieu portfolio

This is a static, responsive portfolio site. Open `index.html` in a browser to preview it.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `nguyen-khac-trieu-portfolio`.
2. Upload `index.html` and `styles.css` from this folder to the repository root.
3. In the repository, open **Settings → Pages**, select **Deploy from a branch**, then select the `main` branch and `/ (root)` folder.
4. Save. GitHub will show the public URL in the Pages settings shortly afterward.

The site includes direct email, phone, GitHub, repository, and test-plan links from the supplied CV.
